# RYA-479 — α Cen optical+IR OBJECT re-split (the RYA-303 analog for non-UV)

Generated by `scripts/resplit_acen_optical_ir_rya479.py`. **Non-destructive** — source
under `data/spectra/.../Alpha Centauri (vetted)/` is read-only (DATA_SAFETY.md). These
products attribute every frame by the authoritative **`OBJECT` header**, not folder name.

## Why
The RYA-301 audit found HARPS/NIRPS/ESPRESSO/CRIRES carry the same A/B-mixing disease
RYA-303 fixed for the STIS UV: folder name ≠ true star. Without this re-split, α Cen A's
abundances would be computed from majority-B photons (a K1V spectrum labelled G2V).

## OBJECT → star normalizer (case/separator-insensitive)
- `HD128620, alf Cen A, alf_Cen_A` → **alpha_cen_a**
- `HD128621, AlphaCenB, alf Cen B` → **alpha_cen_b**
- `Star S5` (+ anything non-α-Cen) → **quarantine**

## Loader contracts (the loader MUST honor)
- **HARPS** `SPECSYS=BARYCENT` → flux already barycentric → **do NOT re-apply BERV**.
- **NIRPS** read a `FLUX_TELL_*` column (`FLUX_TELL_CAL`/`_EL`) + `ATM_TRANSM`, not raw `FLUX`.
- **CRIRES** `WAVE` nm → Å; `SPECSYS=TOPOCENT` (BERV at load); no telluric column → gated.

# Solar N I 7468 Å abundance products

N v1.81 adds the single-feature member of the Caffau et al. 2009 profile-fit selection at 7468.312 Å. The measured oscillator strength is represented by canonical NIST B+ entry pk_7bc78be63b6f. The fit uses the corrected Kitt Peak molecfit holding and resolved profiles reusing the measured carbon sensitivity. The CN term is 0.0226 dex. The telluric test found no corroborated pixels in the feature window.

| Treatment | A(N) | Asplund sigma | Full reported sigma |

| 1D LTE | 7.782 | 0.0682 | 0.0716 |
| Engine A | 7.770 | 0.0682 | 0.0776 |

The LTE result is 0.160 dex below the same-holding two-indicator LTE pool. Both selections are preserved independently. The duplicate Engine B LTE result is present in the calculation artifacts. The existing Solar N products and archive are preserved. [Caffau et al. 2009](https://doi.org/10.1051/0004-6361/200810859)

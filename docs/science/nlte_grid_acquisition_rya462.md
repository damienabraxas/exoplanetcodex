# NLTE grid availability + acquisition (RYA-462)

_The "solar polish": audit every NLTE-relevant grid on three axes — PRESENT (on disk),
WIRED (applied in the default `abundances_derive` run), ABSENT (referenced but no file).
Wire the present-but-unwired grids; acquire (or honestly document) the genuinely absent.
Gated on RYA-461 artifact rescue so we audit what is really on disk before re-fetching._

The live matrix is `data/curation/nlte_grid_availability.csv`, regenerated by
`python scripts/nlte_grid_availability.py`. This note records the verdict + acquisition
status behind it.

## Headline

**K was the only PRESENT-but-UNWIRED production grid.** The
`K_Amarsi2020_PySME.csv` departure grid and the full PySME machinery
(`pipeline/pysme_nlte.py`, RYA-402) already existed; K was simply never added to
`NLTE_CORRECTION_ELEMENTS`, so the default run left it 1D-LTE. RYA-460 had lifted the
old production blocker by measuring the clean **K I 7699** off the Kitt Peak Solar Flux
Atlas (the doublet's other line, 7665, sits in the O2 telluric A-band). RYA-462
registers K and applies its **vendored** solar delta through the existing interpolation
subsystem — the same path Ca/Ti/Cr/Na travel. After wiring, the present-but-unwired
orphan count is **0**.

## Wired this ticket

**K** — `NLTE_CORRECTION_ELEMENTS['K']`, grid `K_Amarsi2020_PySME.csv`, ion 1, flag
`NLTE_Amarsi2020_PySME_1D`. Solar delta applied to the Kitt Peak K I 7699 measurement:

```
A(K) 1D-LTE 5.411  +  delta_NLTE(7699, solar) -0.312  =  A(K) 5.099   (+0.03 vs Asplund 5.07)  -> PASS
```

The delta is **read** from the grid node (5772/4.44/0.0), not fitted — the severe
negative K I resonance NLTE (line much stronger in NLTE) published by Reggiani et al.
2019 / Andrievsky et al. 2006. Verdict moves K **NLTE-OWED -> PASS**; the full solar
Phase C verdict goes 3/2/21/0 -> **4/1/21/0**.

No other present-but-unwired grids exist: S, Al, Si (the ticket's other guesses) are
already registered + applied; the audit confirms it rather than assuming it.

### Cu — no production CSV grid
Cu is measured in the EW pool but **no `Cu_*.csv` departure grid was ever derived**
(only the `.grd` metadata). Per `pipeline/pysme_nlte.py`, Cu NLTE is **small** and the
real blocker is **line quality** (RYA-395 curation: the measured Cu lines are inadequate
and the standard 5105/5220/5782 lines are unmeasured), not the grid. Deriving the CSV
would need PySME + the `.grd`; it would not change Cu's CURATION-OWED verdict. Left as a
documented gap, owed to RYA-395, not RYA-462.

### N I atomic NLTE — owed to RYA-369
The Amarsi-2019 CNO tables (`amarsi2019_cno/`) cover **C/O** synthesis NLTE; the **N I
atomic** departures are a separate, not-yet-vendored grid. This is exactly why N stays
**NLTE-OWED** after the Kitt Peak N I red measurement (+0.37 vs Asplund is the owed
negative N I NLTE). Tracked under RYA-369 — out of scope for the grid-wiring polish.

### Sr II primary grid — manual pull owed (RYA-433)
